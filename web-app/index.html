ABOUT THE PROTOTYPE

Land intelligence, made inspectable.

This educational prototype combines indicative land asking-price evidence with observed development measurements for five selected wards in Bariga, Lagos.

It was built by Abah James Unekwuojo as part of the GeoRAD Academy Emerging Spatial Professional mentorship, using the GeoRAD starter and outputs from Sprints 1–4.

Use with care. Market levels are not formal valuations. NDBI is a proxy for built-up conditions, not a direct building count. The results should be checked before being used for real property decisions.
